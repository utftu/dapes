# Security Policy

Security maintainer: Aleksey Malyuta ([@utftu](https://github.com/utftu))

## Reporting a vulnerability

Report vulnerabilities privately through [GitHub Security Advisories](https://github.com/utftu/dapes/security/advisories/new). Do not open a public issue.

You will get a reply within 7 days.

## Supported versions

Only the latest version published to npm gets security fixes.
